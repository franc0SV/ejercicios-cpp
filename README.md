# 📚 Mis Ejercicios de C++

**Autor:** [franc0SV](https://github.com/franc0SV) · **Ingeniería de Sistemas · USIL**

Recopilación de mis ejercicios de programación en **C++** durante el primer ciclo de la universidad, organizados por semanas. Cada ejercicio incluye el código fuente (`.cpp`), y en varios casos también diagrama de flujo, pseudocódigo y capturas de la consola.

## 📁 Estructura del proyecto

```
C++/
├── PRIMER CICLO/
│   ├── Semana 2 a Semana 14/     # Ejercicios semanales
│   ├── KEYSI/                    # Trabajos y actividades
│   └── TRABAJO FINAL/            # Proyecto final del ciclo
```

| Semana | Contenido |
|--------|-----------|
| Semana 2–4 | Fundamentos: variables, condicionales |
| Semana 5–9 | Bucles, funciones, ejercicios de lógica |
| Semana 10–14 | Arrays, punteros, ejercicios avanzados |
| TRABAJO FINAL | Proyecto integrador del ciclo |

## 🛠️ Herramientas

- **Lenguaje:** C++ (Dev-C++)
- **Editor:** Dev-C++ / compilador gcc
- **Formatos:** `.cpp` (código), `.md` (pseudocódigo/apuntes), `.png` (diagramas y consola)

## 🚀 Cómo ejecutar un ejercicio

1. Entra a la carpeta de la semana que quieras (ej: `PRIMER CICLO/Semana 5`)
2. Abre la carpeta del ejercicio (ej: `ejercicio 1`)
3. Abre `main.cpp` en Dev-C++ (o cualquier IDE que compile C++)
4. Compila y ejecuta con **F11**
